# Manual Twitch roster seeds — one login per line (lowercased).

# Why a roster: Twitch's Search Channels endpoint matches the query against
# channel NAMES, not live stream titles, so searching "box break" can never
# find a live break on a channel named e.g. "LaytonSportsCards". The roster
# poller checks each login's live status directly via streams?user_login=
# (100 logins = 1 API call), so it is effectively free to grow.
#

#   1. Verify the login is really theirs (their own site/socials link it).
#   2. Append the bare lowercase login below (comments with # are ignored).
#   3. Commit + push. The next roster poll seeds it as source='manual'.
